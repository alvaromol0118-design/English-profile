# Alvaro Molina · Web Profile

Bilingual (Spanish / English) personal profile page for the
**Técnico Profesional en Programación Web** program at
Institución Universitaria de El Espinal (UniEspinal).

The language is changed with the **ES / EN** button in the header.

## Sections

| Section | Content |
|---|---|
| Home | Name, role and links to GitHub and email |
| About | Short presentation, city, languages and interests |
| Skills | Technical and professional skills |
| Resume | Education and academic project experience |
| Projects | FINANCE-MOVIL (Laravel, PHP, MySQL) |
| Contact | Email and GitHub |

## Files

- `index.html` · page structure
- `style.css` · styles (colours are defined in `:root`)
- `script.js` · Spanish and English texts, language switcher, menu and skill bars
- `images/` · `profile.jpg` and `project-1.png`
- `NOTES.md` · translation reflection (in English)

## Technical notes

- Only HTML, CSS and JavaScript. No frameworks or build tools.
- Responsive: works on computer and phone.
- Published with GitHub Pages.
